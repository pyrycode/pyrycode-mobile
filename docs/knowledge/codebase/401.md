# #401 — advertise + surface the negotiated `interactive` capability on the v2 hello handshake

The **mobile opt-in** to the Phase 2 structured-streaming exit gate (pyrycode ADR 025): the phone now
advertises `capabilities: ["interactive"]` on every v2 `hello` and **surfaces** the set the daemon
echoes back (the daemon's intersection of advertised ∩ supported) on the existing `PumpState.Open`,
readable through the already-observed `ManagedSessionPump.state`. **Surfacing-only — it gates nothing.**
The decode gate ([#385]) and the stall gate ([#395]) consume the surfaced set later. Split from #369.

Three production files, **zero new exported types**, one new `internal const`. The negotiated set rides
on the existing open-session signal, so no interface and no Koin wiring changed.

## Files touched

Production — 3 modifications:

- **`data/network/MobileWireModels.kt`** — new top-level `internal const val CAPABILITY_INTERACTIVE =
  "interactive"` (`:52`, the wire token, SSOT pyrycode `protocol-mobile.md` § "Capability negotiation
  (v2)"); `HelloClientPayload` gains `val capabilities: List<String> = listOf(CAPABILITY_INTERACTIVE)`
  (`:73`) — the constructor default rides every `hello` via `MobileJson`'s `encodeDefaults = true`, the
  same mechanism that emits `protocol_versions`; the overridden `toString` now surfaces the (non-secret)
  `capabilities` while **keeping `token=***`** (`:75`). `HelloAckPayload` gains `val capabilities:
  List<String> = emptyList()` (`:93`) — the server emits it `omitempty`, so a daemon that grants none
  omits the key and it decodes to the empty default.
- **`data/network/NoiseIkSession.kt`** — new private backing field `negotiatedCaps: Set<String>?`
  (`:79`); new public property `val negotiatedCapabilities: Set<String>` (`:113`) that returns the
  stored set and **throws `IllegalStateException` until the handshake completes**, mirroring `connId`
  (`:104`) verbatim. `parseHelloAck`'s return type changed `String → HelloAckPayload` (`:315`) so a
  second field can be recovered from one decode; `readResp` extracts both — `establishedConnId =
  ack.connId` and `negotiatedCaps = ack.capabilities.toSet()` (`:157-158`) — and **still returns
  `connId`** (the public `readResp(): String` contract is unchanged). The malformed-`hello_ack`
  try/catch and the `type != "hello_ack"` guard are untouched.
- **`data/network/NoiseSessionPump.kt`** — `PumpState.Open` gains a **defaulted second field** `val
  capabilities: Set<String> = emptySet()` (`:299`); `drive()` constructs `PumpState.Open(connId,
  session.negotiatedCapabilities)` (`:164`) — the single production construction, always passing the
  real set. A consumer reads grant with `CAPABILITY_INTERACTIVE in open.capabilities`.

## Patterns established

- **Mirror the `connId` surfacing discipline for a second established-only handshake value.** A value
  recovered from `hello_ack` rides alongside `connId` with the identical shape: a private nullable
  backing field written exactly once in `readResp` on the drive coroutine, behind a public getter that
  `?: throw IllegalStateException` until established (no `!!`). It then surfaces onto `PumpState.Open` as
  a **defaulted** field so every existing `Open(...)` construction/assertion site stays green. Reuse
  this two-step (session property + defaulted `Open` field) for any future negotiated handshake datum.
- **A private decode point returns the DTO, not one field, once it yields more than one.** `parseHelloAck`
  changed `String → HelloAckPayload` so `connId` **and** `capabilities` come from a single
  `decodeFromJsonElement` — no second decode, no second parse boundary.
- **Wire `List` → surface `Set`, converted once at the trust boundary.** The payload models the wire
  shape (`List<String>`); the surfaced type is `Set<String>` because capabilities are a membership set
  ("is `interactive` granted?") and the set dedups/normalises a daemon that repeats an entry. The
  `.toSet()` happens once, in `readResp`, at the post-MAC crossing.
- **Defaulting a new field keeps existing construction sites green** — the same technique as #398's
  `makeVm` defaulted third param and #365's defaulted coordinator ctor params. `PumpState.Open(connId)`
  still compiles and `Open("conn") == Open("conn", emptySet())`, so the four existing `Open` sites (3 in
  `NoiseSessionPumpTest`, 1 in `RelayRepositoryCoordinatorTest`) needed no edit. Adding the field does
  **not** touch `RelayRepositoryCoordinator.toPyrycodeLinkStatus()`'s `is PumpState.Open` match (it
  doesn't destructure).

## Lessons learned

- **`encodeDefaults` serialising a constructor-default list was confirmed by test, not assumed.** The
  ticket flagged "confirm it actually serialises — don't assume." The wire test asserts the literal
  `"capabilities":["interactive"]` substring rather than trusting the `protocol_versions` precedent;
  this is the cheap deterministic guard against a future `MobileJson` config change silently dropping
  the advertisement.
- **Surfacing-only really means it.** This slice deliberately adds **no** convenience boolean
  (`interactiveGranted`) and does **not** re-derive the advertised ∩ echoed intersection client-side.
  The daemon's echo is surfaced **verbatim**; #385 (the first consuming gate) owns treating the set as
  *server-asserted* and intersecting it with the phone's own advertised set before conferring authority.
  Because this layer gates nothing, verbatim surfacing confers no authority and the deferral is sound
  (architect security review SHOULD FIX → hand-off to #385).

## Security

`security-sensitive`. Architect security review **PASS** (no MUST FIX). The untrusted→trusted crossing
is the `hello_ack` early-data, decoded at the single private `parseHelloAck` — which runs **after** Noise
MAC verification (`hs.readMessage` against the pinned server static `rs`) and the `SPLIT` check, so a
relay-operator MITM's forged/tampered `hello_ack` fails the MAC before any `capabilities` byte is parsed.
The surfaced `Set` is therefore exactly as trustworthy as the pinned-key handshake. Token redaction
(`token=***`) is explicitly preserved; only the non-secret `capabilities` is added to `toString`. The
pump's no-logs contract is untouched. The one SHOULD FIX (re-derive the intersection before *acting*) is
an explicit hand-off to #385 — no authority is conferred at this layer.
