# #298 — Noise_IK session: handshake + AEAD transport (initiator)

The **core of the Phase 4 encrypted transport**: the phone's leg of Mobile Protocol v2. A `Noise_IK_25519_ChaChaPoly_BLAKE2s` **initiator** that wraps the vendored `noise-java` ([ADR 0004](../decisions/0004-vendor-noise-java-crypto.md)) to drive the handshake, recover the server's `conn_id`, split into transport ciphers, and expose AEAD `encrypt`/`decrypt` over byte arrays. End-to-end de-risked by the 2026-05-29 proving spike (a `noise-java` initiator interoperated with the Go `flynn/noise` responder against the live `wss://pyrycode-relay.pyryco.de` with zero byte-level debugging). Split from [#275](https://github.com/pyrycode/pyrycode-mobile/issues/275); the WS client + `RemoteConversationRepository` ([#276](https://github.com/pyrycode/pyrycode-mobile/issues/276)/[#278](https://github.com/pyrycode/pyrycode-mobile/issues/278)) and the 1-hour rekey loop ([#299](https://github.com/pyrycode/pyrycode-mobile/issues/299)) are carved off.

See the feature doc [`noise-ik-session.md`](../features/noise-ik-session.md) for the evergreen "how the session works / how #276 + #299 build on it" reference. This file is the implementation record. No new ADR — this ticket **consumes** [ADR 0004](../decisions/0004-vendor-noise-java-crypto.md) (suite + vendored library) and [ADR 0006](../decisions/0006-keystore-wrap-at-rest-device-static-key.md) (how the local `s` is custodied), and aligns with pyrycode-side ADR 024 (Noise_IK for mobile E2E). `security-sensitive` (the asset is the encrypted transport + the device static key, server static, and bearer token).

## Summary

Two production source files **NEW** under `app/src/main/java/de/pyryco/mobile/data/network/` (sibling to the [#273](273.md) wire codec it sits on), plus two DI bindings, verified by two **NEW** pure-JVM unit-test files. **No new dependency, no gradle edit** — `noise-java` is vendored ([#272](https://github.com/pyrycode/pyrycode-mobile/issues/272)/ADR 0004), kotlinx-serialization + kotlinx-datetime + coroutines were already wired.

The session is **byte-array in / byte-array out**: it produces/consumes raw Noise frame bytes and the established `conn_id`. It does **not** own the WebSocket, the `InnerFrameV2` outer framing/base64, or any frame-size cap (all #276), and exposes no rekey op (#299). Four exported types: `NoiseIkSession`, `NoiseSessionFactory`, `NoiseSessionException`, `NoiseClientInfo`. No `NoiseSession` interface was introduced — there is no consumer faking it yet; #276 extracts one when it needs to (evidence-based: no speculative seam).

The load-bearing facts, all spike-proven and pinned by tests:

1. **No prologue.** The constructor calls `start()` and **never** `setPrologue` — `HandshakeState.start()` mixes the empty prologue, and a non-empty prologue diverges the handshake hash so the Go responder rejects msg1. Negatively tested at the library level.
2. **Initiator does not swap on `split()`.** `sender` = encrypt-outbound, `receiver` = decrypt-inbound (the spike's flagged "one high-risk line"). The responder mirror-swaps; the initiator does not.
3. **`ad = null` on every transport op**, and ciphertext length = plaintext + 16 (Poly1305 tag). Both empty-AD and correct-direction are load-bearing — a non-empty AD or a crossed cipher MAC-fails.
4. **Token rides inside the encrypted `hello` early-data**, never a plaintext header (correct v2).

## Files touched

Two production source files **NEW**, one DI edit, two **NEW** JVM test files:

- **`NoiseIkSession.kt`** (248 lines) — the session plus two small companions, **zero `android.*` imports** (operates on byte arrays + `String`s over the pure-Java vendored `noise-java`, `MobileJson`, `kotlinx.datetime`):
  - `data class NoiseClientInfo(deviceName, clientVersion)` — the Android-resolved `hello` identity, injected so the session stays `android.*`-free. Carries no secret → its generated `toString` is fine.
  - `class NoiseSessionException(message, cause?)` — single typed runtime failure (handshake/transport/setup); message names the **category only**, never key material, plaintext, token, or raw bytes.
  - `class NoiseIkSession(localStaticPrivateKey, remoteStaticPublicKey, token, clientInfo)` — **a plain `class`, deliberately NOT a `data class`** (it retains `token` as `pendingToken` until `writeInit`; a generated `toString` would print it to a crash frame — the identity `toString` leaks nothing). Internal `enum State { NEW, AWAITING_RESP, ESTABLISHED, CLOSED }`.
    - **Constructor**: `require` both keys are 32 bytes; build `HandshakeState(PROTOCOL, INITIATOR)` (wrap `NoSuchAlgorithmException` → `NoiseSessionException`); `localKeyPair.setPrivateKey(localStaticPrivateKey, 0)` (derives the matching public key); `remotePublicKey.setPublicKey(remoteStaticPublicKey, 0)` (pins `rs`); `start()`. Setup is eager (not lazy) so the raw private key is copied into the DH state immediately, shrinking its RAM window.
    - **`writeInit(): ByteArray`** (NEW → AWAITING_RESP): build the `hello` envelope, `writeMessage` into a buffer sized `hello.size + IK_MSG1_OVERHEAD` (96 = 32-byte `e` + 48-byte encrypted `s` + 16-byte payload MAC), `pendingToken = null` (sealed into the ciphertext — drop the reference), return `out.copyOf(n)`.
    - **`readResp(resp): String`** (AWAITING_RESP → ESTABLISHED): `readMessage` into `ByteArray(resp.size)`; `check(action == SPLIT)`; parse `hello_ack` → `connId`; `split()`; assign `sender`/`receiver`; return `connId`. **Fail-closed**: the whole body is `try { … } catch (e) { state = CLOSED; throw e } finally { hs.destroy(); handshake = null }` — any failure transitions to CLOSED (not a half-open AWAITING_RESP), and the handshake (device-key copy + handshake secrets) is **always** wiped post-`split()`. `BadPaddingException` → `NoiseSessionException("noise_resp handshake verification failed")`; `ShortBufferException` → `NoiseSessionException("malformed noise_resp")`.
    - **`val connId: String`** — throws `IllegalStateException` until established.
    - **`encrypt(plaintext): ByteArray`** / **`decrypt(ciphertext): ByteArray`** (ESTABLISHED only) — `encryptWithAd(null, …)` / `decryptWithAd(null, …)`; `decrypt` guards `ciphertext.size >= MAC_SIZE` (`NoiseSessionException` else) and maps `BadPaddingException` → `NoiseSessionException("frame authentication failed")`. **Both `@Synchronized`** (see Patterns).
    - **`close()`** (`@Synchronized`) — destroy handshake (if still held) + `CipherStatePair`; null the ciphers + `pendingToken`; idempotent; subsequent ops throw `IllegalStateException`.
    - Companion constants: `PROTOCOL = "Noise_IK_25519_ChaChaPoly_BLAKE2s"`, `KEY_SIZE = 32`, `MAC_SIZE = 16`, `IK_MSG1_OVERHEAD = 96`.
  - `buildHello()` / `parseHelloAck()` — **always `MobileJson`** (never a fresh `Json {}` — defaulted-field omission is wire-breaking, see [#273](273.md)). `hello` = `HelloClientPayload(deviceName, clientVersion, token)` (`role`/`protocolVersions` default) wrapped in `Envelope(id = 1L, type = "hello", ts = Clock.System.now().toString(), payload = encodeToJsonElement(hello))`. `hello_ack` recovery: decode `Envelope`, `require type == "hello_ack"`, decode `HelloAckPayload` → `connId`; any `SerializationException`/wrong-type/missing-`conn_id` → `NoiseSessionException("malformed hello_ack")` (no payload bytes in the message).
- **`NoiseSessionFactory.kt`** (58 lines) — resolves the crypto inputs and constructs a ready-to-handshake session, also portable (`android.*`-free):
  - `class NoiseSessionFactory(deviceStaticKeyStore, pairedServerStore, clientInfo, ioDispatcher = Dispatchers.IO)`.
  - `suspend fun create(): NoiseIkSession` in `withContext(ioDispatcher)`: `load()` the `PairedServer` (`null` → `NoiseSessionException("not paired")`); `base64StdDecode(serverStaticPublicKey)` (bad base64 `IllegalArgumentException` → `NoiseSessionException("invalid server static key")`) + re-validate **exactly 32 bytes** (mirrors `decodeServerStaticPubkey`, no echoed bytes); `loadOrCreate(serverId)` (`DeviceStaticKeyException` → `NoiseSessionException("device static key unavailable")`, cause preserved); construct the session, then **zero the private-key buffer** (`keyPair.privateKey.fill(0)` — the constructor has already copied it into the DH state). Every setup failure collapses into one `NoiseSessionException` (cause chain preserved), so #276 catches one type to surface "re-pair / retry". Does **not** open a socket.
- **`di/AppModule.kt`** (+6 lines) — `single { NoiseClientInfo(deviceName = Build.MODEL, clientVersion = BuildConfig.VERSION_NAME) }` + `single { NoiseSessionFactory(get(), get(), get()) }` (resolving the already-registered `DeviceStaticKeyStore` + `PairedServerStore`), plus the two imports for `android.os.Build` / `BuildConfig`. The only Android-bound values (`Build.MODEL`, `VERSION_NAME`) are resolved **here** (the module is Android-bound) and injected as plain strings, keeping the session portable. ## Patterns established

- **Deterministic nonce-reuse safety net (`@Synchronized` on `encrypt`/`decrypt`/`close`).** The `sender`/`receiver` `CipherState`s each hold a monotonic nonce counter; two concurrent same-direction calls could race read-then-increment → **nonce reuse**, which for ChaCha20-Poly1305 is silent and catastrophic (keystream reuse → confidentiality loss). Expected usage is a single WS message pump (one outbound, one inbound at a time), so it shouldn't happen — but a doc-only contract is a single stochastic layer guarding a silent catastrophe. Per **belt-and-suspenders**, pair the KDoc single-pump contract with a **deterministic** net: the session's intrinsic lock. `encrypt` and `decrypt` use different cipher objects so they never deadlock and stay independent; a contract violation degrades to harmless serialization instead of nonce reuse. (Contrast the Go side, where `V2Session` carries **no** mutex because the per-conn dispatch loop *is* the lock — here the consumer #276 is not yet written, so the session ships its own floor.)
- **Plain `class` (never `data class`) for a secret-bearing session object.** `NoiseIkSession` retains `token` until `writeInit`; a `data class`'s generated `toString` would leak it to any crash frame / stray `Log.d("$session")`. The identity `toString` (`NoiseIkSession@hash`) leaks nothing. (Complements [#294](294.md)'s rule — a secret-bearing *value type* that wants structural `equals` overrides `toString()` to a non-secret projection; a secret-bearing *behavioural* object stays a plain class.)
- **Fail-closed handshake with a `finally`-wiped handshake state.** `readResp` transitions to `CLOSED` on **any** throw (not a half-open AWAITING_RESP), and `hs.destroy()` runs in `finally` so the device-key copy + handshake secrets are wiped whether the handshake succeeds or fails — bounding the device-static-key RAM window to the handshake regardless of outcome.
- **Injectable `ioDispatcher` to make a store-backed factory JVM-unit-testable.** The spec sized the factory test as "optional / light"; injecting `ioDispatcher: CoroutineDispatcher = Dispatchers.IO` (default preserves production behaviour) let `NoiseSessionFactoryTest` drive `create()` under an `UnconfinedTestDispatcher` with faked stores — a full 4-test wiring suite for ~free. (A small, justified divergence from the spec's literal `withContext(Dispatchers.IO)`; the same NIT #294/#291 left deliberately undone, taken up here because the factory has branch logic worth pinning.)
- **Defensive `ShortBufferException` mapping.** Beyond the spec's error table (which named only `BadPaddingException`), both `readResp` and `decrypt` also catch `ShortBufferException` → `NoiseSessionException("malformed …")`, so a truncated/garbage frame surfaces as the one clean type #276 catches, never a raw library leak.

## Lessons learned

Lifted from the PR's *Lessons learned* section:

- **`handshake.destroy()` after `split()` is safe — `split()` forks independent cipher states.** `SymmetricState.split()` calls `cipher.fork(k1/k2)`, so the transport `CipherStatePair` does **not** alias the handshake's internal cipher; destroying the `HandshakeState` post-`split()` wipes the device-key copy + handshake secrets without touching the live transport keys. This is what lets `readResp` wipe the handshake in `finally` while keeping the session usable — and bounds the device-static-key RAM window to the handshake, not the whole session.
- **`kotlinx-coroutines-test` forces stack-trace recovery on — assert cause-chain *membership*, not direct `.cause`.** An exception crossing `withContext` is wrapped in a recovered *copy* whose direct `.cause` is the original thrown exception (not its underlying cause). So `assertEquals(deviceKeyException, thrown.cause)` would fail. The factory test walks the chain instead: `generateSequence<Throwable>(thrown) { it.cause }.any { it === cause }`. Any test asserting a preserved cause across a `withContext` boundary must do the same.
