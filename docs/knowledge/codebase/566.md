## Summary

Adds `interactiveTurn_createWorkspaceFolder_usableAsLiveSessionWorkspace` to
`InteractiveStreamE2ETest` — a rung-3 real-claude scenario that drives the #564/#565 happy path end to
end: long-press the channel-list FAB → Workspace Picker → "Create new folder…" → type a
collision-resistant name → land in a fresh discussion whose workspace **is** the created folder →
send the constrained ping and assert the reply renders (proving the folder is a usable live-session
workspace) → re-open the picker from the channel list and assert the folder shows in "Recent". Two
files change, **zero production surface** — this ticket only adds test code and extends the LIVE gate
runner.

Reachability was the open question carried from the #535 split: unlike the #537 rename-family e2e
(unbuildable — hidden behind `mutationsSupported`), the create-folder affordance is **ungated** on the
live build, so this scenario ships a real, mergeable slice rather than parking to Inbox.

## Patterns established

None new — this is a confirming instance of the rung-3 real-claude scenario shape (#481/#482's
template): a `@Test` cloning the ping scenario's wait/act/assert skeleton, tolerant asserts only,
constants added to the shared companion object. The one generalizable move is **extending a `LIVE`
gate from one curated method to a comma-separated list** — future rung-3 scenarios that earn a LIVE
slot follow the same `TEST_CLASS#methodA,TEST_CLASS#methodB` shape rather than a positional arg or a
separate script invocation.

## Lessons learned

- **Compose `Text` exposes its full string to the semantics tree even when visually truncated**
  (`maxLines=1` + `TextOverflow.Ellipsis`). A substring match + `assertIsDisplayed()` on a long recents
  path or chip label is therefore robust to on-screen ellipsis — the folder-name token is still present
  semantically and the node is still displayed, even if the rendered pixels truncate it. (From the PR's
  own "Lessons learned" section.)
- **Reachability can flip from "gated" to "buildable" between a split's parking and its follow-up.**
  The #535 split originally deferred this e2e pending a `mutationsSupported`-style reachability check
  (the #537 precedent); by the time this ticket ran, PO re-verification confirmed the create affordance
  is ungated, so the scenario shipped directly rather than parking. Re-verify reachability at pickup
  time rather than trusting a stale park rationale.
